# پورتفولیوی مصطفی مومنی

وب‌سایت شخصی **مصطفی مومنی (Mostafa Momeni)** — برنامه‌نویس Frontend و هوش مصنوعی.

پروژه با **Next.js (App Router)** و **JavaScript خالص** ساخته شده است. عمداً از
**TypeScript** و **Tailwind CSS** استفاده نشده و تمام استایل‌ها با CSS دست‌نویس
(متغیرهای CSS، Flexbox/Grid، ریسپانسیو) نوشته شده‌اند.

---

## راه‌اندازی

```bash
npm install
npm run dev      # حالت توسعه روی http://localhost:3000
npm run build    # ساخت نسخه پروداکشن
npm start        # اجرای نسخه پروداکشن
```

پیش از انتشار، آدرس سایت را در متغیر محیطی زیر تنظیم کنید (برای متادیتا،
اسکیمای گوگل و نقشه سایت استفاده می‌شود):

```bash
NEXT_PUBLIC_SITE_URL=https://example.com
```

## ساختار پروژه

```
app/
  layout.js                متادیتای SEO و داده ساخت‌یافته (Person / WebSite / CreativeWork)
  page.js                  صفحه اصلی — ترکیب بخش‌ها
  globals.css              کل سیستم طراحی (توکن‌ها، اجزا، ریسپانسیو)
  icon.svg                 فاوآیکون
  opengraph-image.js       تصویر اشتراک‌گذاری (با فونت فارسی)
  robots.js                robots.txt
  sitemap.js               sitemap.xml
  not-found.js             صفحه ۴۰۴
  projects/[slug]/page.js  صفحه جزئیات هر پروژه (با generateStaticParams)

components/                کامپوننت هر بخش
data/site.js               تنها منبع حقیقتِ محتوا
public/
  fonts/                   فونت وزیرمتن (خودمیزبان)
  projects/                تصاویر پروژه‌ها
```

### اصل مهم: `data/site.js`

تمام محتوای سایت — از نام و رزومه تا پروژه‌ها و مهارت‌ها — در یک فایل جمع شده
است. برای تغییر هر متن فقط همین فایل را ویرایش کنید؛ نیازی به دست‌زدن به
کامپوننت‌ها نیست.

## منابع محتوا

طبق درخواست، **هیچ اطلاعاتی ساخته نشده است**. هر داده از یکی از این منابع واقعی
آمده و در `data/site.js` مشخص شده است:

| منبع | استفاده |
| --- | --- |
| رزومه فرانت‌اند (`final-front-rsume.pdf`) | سوابق شغلی، تحصیلی، پروژه‌ها و تاریخ‌ها |
| رزومه هوش مصنوعی (`ai_resume.pdf`) | مهارت‌های AI و پروژه بورس |
| پروفایل و مخازن عمومی GitHub | آمار مخازن و فناوری واقعی هر پروژه |
| خودِ وب‌سایت پروژه‌ها | عنوان، توضیحات و فناوری‌ها (از هدرهای فنی سایت) |

مواردی که **عمداً نمایش داده نشده‌اند**: آمار ساختگی، درصد مهارت، نظر مشتری،
تعداد کاربر، و هر ادعای بدون منبع.

### تصاویر پروژه‌ها

تصویر هر کارت یکی از این دو نوع است:

- **اسکرین‌شات واقعی** از همان وب‌سایت زنده (`9falak`, `chipyab`, `irzar`, `nextafzar`)
- **نشان رسمی پروژه** روی پس‌زمینه گرادیانی، وقتی اسکرین‌شات در دسترس نبوده
  (`tafsir`, `chart-9falak`) — این تصاویر **ادعای اسکرین‌شات نمی‌کنند**

پروژه **محرمانه** (`ai-stock-market`) هیچ تصویری ندارد و به‌جای آن با نشان قفل
نمایش داده می‌شود، چون اجازه انتشار کد و دمو آن داده نشده است.

### درباره دو رزومه

دو رزومه (فرانت‌اند و هوش مصنوعی) به یک پورتفولیوی واحد برای یک نفر ادغام
شده‌اند و مهارت‌های مشترک (مثل React، Python، Git) فقط یک‌بار نمایش داده
می‌شوند.

## ویژگی‌ها

- **RTL واقعی** با `dir="rtl"` و فونت وزیرمتن خودمیزبان
- **ریسپانسیو** از ۳۲۰ تا ۱۴۴۰ پیکسل (دسکتاپ، لپ‌تاپ، تبلت، موبایل)
- **انیمیشن ورود** با `IntersectionObserver` و احترام به `prefers-reduced-motion`
- **SEO**: متادیتای کامل، Open Graph، Twitter Card، canonical، داده ساخت‌یافته
- **دسترس‌پذیری**: HTML معنایی، `alt` روی همه تصاویر، ناوبری با صفحه‌کلید،
  لینک پرش به محتوا، کنتراست مناسب
- **کارایی**: تصاویر WebP، بارگذاری تنبل، فونت با `font-display: swap`،
  خروجی کاملاً استاتیک (SSG)
- **امنیت لینک‌های خارجی**: همه با `rel="noopener noreferrer"`
